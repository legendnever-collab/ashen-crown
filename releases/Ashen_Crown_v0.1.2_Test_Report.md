## 중요한 검증 내용

- 이동 모션의 중간 위치와 각 타일에서의 짧은 정지 확인. 경로의 장애물/점유/지형 비용은 기존 이동 함수 하나를 사용합니다.
- 이동 도착 후 확인 메뉴가 표시되더라도 실제 State·RNG·이동권·저장 값이 원래와 동일. 취소와 미확정 Reload도 원래 위치를 유지합니다.
- 미확정 이동 중 다른 행동·턴 종료를 차단. 확정은 이동권을 1회만 사용하고, 공격 전 Undo 가능.
- 즉시 이동 옵션도 확정을 생략하지 않습니다. 걷기 종류와 약한 효과 옵션은 새로고침 후 복원됩니다.
- 실제 Fire Bolt 사용을 프레임 간 샘플링하여 Cast/Flight/Explosion을 관측. 피해 피드백은 폭발 구간에 발생하며 MP/행동권은 정상 소모합니다.
- 실제 화살의 Flight/Impact, 적 AI의 도끼 Swing을 관측. 순수 연출 테스트에서 적 이동 완료 후 공격, 첫 공격 종료 후 반격, 각각의 착탄 HP 시점을 확인합니다.
- 회복약은 카테고리→사용 확인을 거쳐 HP 상한·도구 개수·행동 소모에 반영. 만피에서는 비활성화.
- 스킬 하위 메뉴의 실제 비용/스킬 이름, 고유 재능/잠재력/미해금 안내, 화면 안 메뉴와 확정 버튼, 페이지 Overflow 없음.
- 실제 Map Tap과 버튼으로 주민 2명 구출, 증원, 산적 대장 격파, 승리, 성장, Save/Reload, Replay를 완주. 자연 패배 후 Retry도 확인. 쓰기 가능한 테스트 State API나 승리 우회는 없습니다.
- 실제 이전 v0.1.0 및 v0.1.1 HTML이 생성한 전투 백업을 복원하고 유닛·성장·RNG·Schema 1 동일성 확인.

## 시각 검수와 플레이 관찰

브라우저에서 생성한 이동 확인, 4개 모바일 예측 화면, 화염탄 비행/폭발, 승리/패배 화면을 직접 시각 검수했습니다. 메뉴가 전장을 가릴 때 이동/대상 선택을 시작하면 닫히고, 목적지나 대상을 고르면 확인 메뉴가 다시 나타납니다. 하단 얼굴과 HP/MP는 유지됩니다. 작은 가로 화면에서는 메뉴 내부 스크롤과 확대/팬을 사용할 수 있습니다.

검수 중 터치 직후 Canvas 전체에 브라우저 기본 청색 강조가 잠시 덮이는 현상을 발견해 제거했습니다. 새 옵션의 한글 글리프를 포함하도록 내장 폰트를 갱신했습니다. 초기 연출 단위 테스트의 700ms 비교는 부동소수점 오차를 허용하도록 수정했고, 스킬 메뉴 검사는 임의 비용 대신 실제 캐릭터 데이터를 사용하도록 수정했습니다. 최종 실행은 모두 PASS입니다.

이는 개발자 시각 검수와 자동 UI 완주 결과입니다. 별도 사람의 자유 플레이 재미 평가나 실제 스마트폰 하드웨어 테스트를 통과했다고 주장하지 않습니다. 칸별 걷기와 확인은 피드백을 강화하지만 턴 처리 시간이 늘어나므로 빠른 플레이를 위해 속도/즉시 이동 옵션을 제공합니다.
