# QA_REPORT — G2 B: 각성 다리오

## 결과
- PASS: 초상 4장(기본/걱정/결의/슬픔), 각각 정확히 1024×1280 PNG RGBA.
- PASS: 맵 시트 1장, 정확히 1024×768 PNG RGBA, 256×256 셀 4열×3행.
- PASS (육안): 기존 다리오의 성숙한 얼굴, 수염, 묶은 어두운 머리, 피부색을 유지했다. 참조 그림의 그림체/따뜻한 가장자리 빛을 따랐다.
- PASS (육안): 네 초상은 같은 인물, 와인색 하이칼라 의상, 검은 가죽, 무문양 은색 잠금장치, 두 칼집, 구도와 조명을 공유한다. 표정 차이가 읽힌다.
- PASS (육안): 맵 시트는 새 초상의 복장과 색을 따른다. 행은 아래/오른쪽/뒤, 열은 대기/걷기 A/걷기 B/공격이다. 두 번째 행은 화면 오른쪽을 향한다.
- PASS (수치): 12개 셀의 알파 경계가 모두 셀 내부다. 가장자리에서 잘린 무기나 인물은 없다. 모든 프레임은 동일한 배율로 리사이즈했다.
- FAIL (엄격한 발 기준선): 실루엣 최하단을 각 셀의 y=239에 정렬했다(아래 16픽셀 여백). 일부 프레임에서는 칼끝이 발보다 아래에 있어 발바닥 자체의 기준선은 정확히 같지 않다. 정확한 발 피벗을 요구하는 엔진에서는 추가 보정이 필요하다. 실루엣 정렬을 발바닥 정렬로 간주하지 않았다.

## 명시적 차이와 한계
- 생성형 표정 편집이므로 얼굴 바깥도 미세한 음영/질감 차이가 있다. 얼굴 이외 픽셀이 완전히 같은 이미지라고 주장하지 않는다.
- 초상에서는 두 무기가 칼집에 있어 칼날 가장자리의 은빛은 뚜렷이 보이지 않는다. 맵 시트에서는 무기 금속광으로 나타난다.
- 초상의 머리 위 여백은 약 6%로 요청의 약 8%보다 작다. 기존 참조와 같은 어깨/허리 구도를 우선했다.

## 제작 및 정규화
- 제공된 프롬프트와 참조 그림을 사용해 내장 이미지 생성 도구로 제작했다. 실제 입력한 프롬프트와 수정 프롬프트를 `prompts_used/`에 포함했다.
- 생성 원본의 크기가 요청 크기와 달라 종횡비를 유지한 리사이즈와 투명 여백 배치로 규격을 맞췄다. 가로/세로를 따로 늘리지 않았다.
- PNG는 모두 실제 RGBA 투명 배경이다. 초록색 대체 배경이나 WebP는 사용하지 않았다.
- PASS: PNG를 다시 열어 디코딩 및 크기/알파 검사. 미리보기 JPEG는 1 MB 미만.
- PASS: 최종 이미지를 어두운 배경의 contact sheet로 육안 확인했다. 글자, 문장, 숫자, 로고, 문장(紋章), 종교 표식은 보이지 않는다. 금속 잠금장치와 인장은 무문양이다.
- 게임에 실제 적용한 애니메이션 재생 검증은 이 작업에 포함되지 않았다.

## ZIP 무결성 검사
- 최종 포장 후 ZIP을 다시 열어 전체 파일 목록과 CRC를 검사한다.
- `SHA256SUMS.txt` 자체를 제외한 모든 파일을 SHA-256 목록과 대조한다. 누락/추가 파일도 검사한다.
- 위 두 검사를 통과한 ZIP만 전달한다. 개별 ZIP은 20,000,000 바이트 미만이다.
