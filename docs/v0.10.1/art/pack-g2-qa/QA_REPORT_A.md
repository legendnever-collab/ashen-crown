- PASS (수치): 01–07에만 아이콘이 있고 08–16의 모든 픽셀은 alpha=0이다.
- PASS (수치): 모든 아이콘의 전체 알파 경계가 각 셀의 26≤x,y<230 안전 영역 안에 들어간다. 최대 폭/높이는 204픽셀이다.
- PASS (육안): 순서는 교차한 두 검/검은 창과 사자 연기/사자 포효와 방패/무문양 검은 깃발과 두 방패/기마 돌격과 화살 고리/청·녹·적색 무문양 인장/금색 고리로 묶은 검은 갈기다.
- PASS (육안): 제공한 승인 아이콘과 유사한 회화적 금속/천 질감, 따뜻한 빛과 어두운 외곽을 사용했다. 40×40 축소판에서 각 핵심 형상을 확인했다.
- PASS: 빈 셀, 셀 경계, 도형 잘림 및 주변 배경 혼입을 최종 파일에서 확인했다.

## 명시적 차이와 한계
- 05번은 작은 기마병 실루엣으로 돌격을 표현했다. 창/화살의 원형 운동과 함께 보이며, 일곱 아이콘 중 가장 복잡한 실루엣이다.
- 마법의 빛 효과는 각 아이콘에 포함되어 있고 외부 셀로 번지지 않는다. 아이콘 사이의 넓은 배경/안개는 없다.

## 제작 및 정규화
- 제공된 프롬프트와 참조 그림을 사용해 내장 이미지 생성 도구로 제작했다. 실제 입력한 프롬프트와 수정 프롬프트를 `prompts_used/`에 포함했다.
- 생성 원본의 크기가 요청 크기와 달라 종횡비를 유지한 리사이즈와 투명 여백 배치로 규격을 맞췄다. 가로/세로를 따로 늘리지 않았다.
- PNG는 모두 실제 RGBA 투명 배경이다. 초록색 대체 배경이나 WebP는 사용하지 않았다.
- PASS: PNG를 다시 열어 디코딩 및 크기/알파 검사. 미리보기 JPEG는 1 MB 미만.
- PASS: 최종 이미지를 어두운 배경의 contact sheet로 육안 확인했다. 글자, 문장, 숫자, 로고, 문장(紋章), 종교 표식은 보이지 않는다. 금속 잠금장치와 인장은 무문양이다.
- 게임에 실제 적용한 애니메이션 재생 검증은 이 작업에 포함되지 않았다.

## ZIP 무결성 검사
- 최종 포장 후 ZIP을 다시 열어 전체 파일 목록과 CRC를 검사한다.
- `SHA256SUMS.txt` 자체를 제외한 모든 파일을 SHA-256 목록과 대조한다. 누락/추가 파일도 검사한다.
- 위 두 검사를 통과한 ZIP만 전달한다. 개별 ZIP은 20,000,000 바이트 미만이다.
