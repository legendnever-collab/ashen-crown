## 1. 일기토 규칙 (지금 → 바뀌는 점)

| | v2.1.0 (지금) | v2.2.0 (설계안) |
|---|---|---|
| 일어나는 조건 | 인연 있는 아군 장수가 짝인 적 주연급의 옆 칸에 섬. 한 전투에 짝마다 한 번 | 그대로 |
| 진행 | 대사 두 줄 → 잿빛 결투장에서 베기·막기·노리기(가위바위보) 또는 「물러선다」 | 대사 두 줄 → **새 창에서 일기토 장면(약 10초)**. 고르는 단계 없음. 화면을 누르면 건너뛰지만 결과는 같음 |
| 결과 | 이길 수도 질 수도 있음. 진 쪽 HP −30% | **우리 장수가 반드시 이김** |
| 보상 | 상대가 가진 보물 | 보물 + **우리 장수 레벨 +1**(성장치도 레벨업과 같이 오름, 레벨업 연출 포함) |
| 진 상대 | HP −30% | **HP가 현재의 1/3로**(최소 1). 죽지 않으므로 이야기 진행(발드릭 설득·합류, 벨라드 2단계 등)은 그대로 |
| 이야기 일기토 (M16·M20·M21·M26·M29) | 결과에 따라 대사·효과가 갈림 | 언제나 「이김」 쪽으로 진행. M26 결단 +2, M29는 이긴 쪽 대사 |

- 「물러선다」 선택지는 없앱니다. 일기토가 일어나면 반드시 장면이 재생됩니다.
- 레벨 상한(30)에 닿은 장수는 레벨 대신 경험치를 채웁니다. 최고 레벨이면 성장 보너스 +1을 받습니다(PROPOSED).
- 어려움 난이도에서도 반드시 이깁니다. 대신 상대 HP는 1/2로 남깁니다(PROPOSED).

## 2. 일기토 장면 (새 창)
화면 가운데 16:9 무대를 띄우고, 바깥은 어둡게 합니다. 휴대폰 세로 화면에서는 가로 폭에 맞추고 위아래를 검게 둡니다.

| 시간 | 연출 | 쓰는 그림 |
|---|---|---|
| 0.0s | 창이 열리고 장소 배경이 미끄러져 들어옴 | 일기토 배경(5종 중 미션에 맞는 것) |
| 0.5s | 두 사람의 초상이 양쪽에서 들어오며 이름과 「一騎討 · 일기토」 | 기존 대화 초상 |
| 1.5s | 이야기 대사 두 줄 | — |
| 3.0s | 두 사람이 준비 자세로 등장 | 동작 시트 1 준비 |
| 3.6s | **1합**: 둘 다 돌진 → 칼 맞대기(불꽃·흔들림) → 상대가 밀려남 | 2 돌진 · 4 맞대기 · 6 밀려남, 효과 불꽃·먼지·속도선 |
| 5.2s | **2합**: 상대의 강공을 막아 냄(방패 섬광) → 되받아침 | 상대 3 공격, 우리 5 막기 · 3 공격, 효과 섬광·베기 궤적 |
| 6.8s | **3합**: 슬로모션 결정타. 화면이 번쩍이며 결정타 컷이 0.8초 동안 화면 가득 | 7 결정타, 결정타 컷, 효과 충격파·땅 갈라짐 |
| 8.4s | 상대는 무릎 꿇음, 우리 장수 승리 자세 | 8 마무리 |
| 9.0s | 금빛 기둥과 **LEVEL UP** · `LV 7 → 8`, 오른 능력치 표시 | 효과 빛기둥·반짝임 |
| ~10s | 창이 닫히고 전장으로 돌아감(상대 HP 1/3, 보물 획득 알림) | — |

- 움직임은 게임이 만듭니다. 미끄러지듯 이동, 확대·축소, 슬로모션, 화면 흔들림, 번쩍임, 잔상, 효과를 빛으로 겹치기.
- 동작을 하나씩 정하는 기준
  - 무기가 다른 장수(활·마법·지팡이)는 같은 8컷을 자기 방식으로 그립니다. 예를 들어 리아의 「칼 맞대기」는 지팡이 끝 마법이 부딪치는 그림입니다.
  - 그림이 아직 없는 사람은 지도 그림(병종 그림)을 크게 키워 같은 흐름으로 보여 줍니다(임시).
- 「효과 약하게」 설정을 켜면 흔들림과 번쩍임을 줄이고 슬로모션을 짧게 합니다.
- 소리: 기존 효과음(칼, 충격, 레벨업)을 씁니다.

## 4. 어느 동작 시트를 쓰나
- 우리 장수는 각성(3단계) 뒤에는 각성 시트를 씁니다. 그 전에는 기본 시트를 씁니다.
