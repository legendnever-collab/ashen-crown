# Ashen Crown v2.2.0 — 일기토 장면과 새 주점

**일기토가 벌어지면 우리 장수가 반드시 이기고 레벨이 하나 오릅니다. 싸움은 따로 열리는 창에서 짧은 액션 장면으로 보여 줍니다. 잿빛 마을 주점은 새 그림으로 바뀌었습니다.**

상태: **릴리스 후보**(feature/v2.2.0-duel). 직접 플레이해 보시고 승인하시기 전에는 병합하지 않습니다.
- 개발 지시: 2026-11-18 23:22 「이 그림과 일기토 장면과 '반드시 승리 + 레벨업' 규칙을 지금 임시 그림으로 먼저 만들어 v2.2.0 후보」(D-123)
- 설계: [DUEL_SCENE_DESIGN.md](DUEL_SCENE_DESIGN.md) · 그림 지시서: `docs/v2.2.0/art/duel-work-pack`(그림팩 I, 59장)
- 수치와 연출은 모두 제안값(PROPOSED)입니다. 플레이해 보시고 말씀해 주시면 고칩니다.

## 1. 일기토 규칙

| | v2.1.0 | v2.2.0 |
|---|---|---|
| 일어나는 조건 | 인연 있는 장수가 적 주연급 옆 칸에 섬 | 그대로 |
| 진행 | 대사 두 줄 → 결투장에서 베기·막기·노리기 고르기, 또는 「물러선다」 | 대사 두 줄 → **일기토 창**(약 9초). 고르는 단계 없음 |
| 결과 | 이길 수도 질 수도 있음 | **우리 장수가 반드시 이김** |
| 우리 장수 | 이기면 상대의 보물을 얻음 | 보물 + **레벨 +1**(레벨업이므로 HP·MP 모두 회복) |
| 상대 | 지면 HP −30% | HP가 **지금의 1/3**(어려움은 1/2). 죽지 않으므로 이야기는 그대로 이어짐 |

- **M29 벨라드만 예외입니다.**
  - 원래 이야기에서 에릭이 물러서면, 아렌이 벨라드에게 마지막 말을 건넵니다. 이 말이 벨라드의 운명에서 「제안」 선택을 엽니다.
  - 이야기와 엔딩을 지키기 위해 M29에서만 「에릭이 나선다(일기토) / 아렌에게 맡긴다」를 고릅니다.
  - 에릭이 나서면 반드시 이깁니다.
- 이야기 일기토도 모두 이긴 쪽으로 이어집니다.
  - M26: 결단 +2
  - M16 · M20 · M21 · M29: 이긴 쪽 결과
  - 발드릭은 1/3로 남으므로 설득하고 합류시키는 흐름이 그대로 이어집니다.

## 2. 일기토 창

| 시간 | 장면 |
|---|---|
| 0–1.5초 | 검은 띠가 내려오고, 장소 배경 위로 두 사람의 초상이 양쪽에서 들어옵니다(「일기토 · VS」, 장소 이름) |
| 1.5–3.4초 | 두 사람이 들어와 동시에 돌진하고 칼이 맞물립니다(불꽃, 화면 흔들림). 상대가 밀려납니다 |
| 3.4–5.1초 | 상대가 강하게 공격하고, 우리 장수가 막아 낸 뒤(방패 섬광) 베어 냅니다 |
| 5.1–7.2초 | 우리 장수가 달려들어 **슬로모션 결정타**를 넣습니다(화면 번쩍임, 빛살, 충격파). 상대는 무릎을 꿇습니다 |
| 7.2–9.4초 | 금빛 기둥이 솟으며 **LEVEL UP · LV a → b**가 뜹니다 |

- 장소 배경은 미션에 따라 다섯 가지입니다.

| 배경 | 미션 |
|---|---|
| 불타는 잿빛 마을 | M01 |
| 국경의 숲길 | M05 · M09 · M18 |
| 성채 마당 | M10 · M13 · M16 · M25 |
| 의식 광장 | M12 · M19 · M20 · M21 |
| 왕관의 홀 | M26 · M29 |

- **건너뛰기**는 오른쪽 아래 버튼, 또는 Esc · Enter · Space로 합니다. 결과는 장면을 열기 전에 이미 정해져 있어, 건너뛰거나 새로 고침해도 같습니다.
- 「효과 약하게」를 켜면 화면 흔들림과 번쩍임을 끄고 슬로모션을 줄입니다.
- 휴대폰을 세로로 들면 무대를 키우고 양옆을 조금 잘라 보여 줍니다.
- **지금은 임시 그림입니다.**
  - 인물: 지도 그림을 크게 키워 자세를 기울여 보여 줍니다.
  - 배경·빛 효과: 게임이 직접 그립니다.
  - 그림팩 I의 동작 시트(B–E), 결정타 컷(F), 배경·효과(G)가 오면 그대로 바꿔 끼웁니다.

## 3. 새 주점 (그림팩 I · A)
- 잿빛 마을 주점 그림을 받은 것으로 바꿨습니다(SHA256 확인).
  - 왼쪽: 바 카운터와 술통, 술병 선반
  - 가운데: 의뢰 게시판
  - 오른쪽: 돌 벽난로와 장작
  - 둥근 탁자와 긴 탁자, 등불
- 주인은 **바 뒤**에 서 있습니다. 바 앞으로 가서 말을 거세요.
- 걸을 수 있는 칸과 상자 두 개의 자리도 그림에 맞춰 새로 정했습니다.
- 다른 마을 주점은 그대로입니다.
