# Ashen Crown v0.9.2 — ACT III F3 A: QA report

제작 순서: B → C → A. 내장 이미지 생성으로 원본을 제작하고, 요청된 크롭·등방 리사이즈·패딩으로 최종 PNG 규격을 맞췄습니다. 표현/복장 수정에도 같은 생성 도구를 사용했습니다. 최종 이미지가 있는 png/만 게임 적용 대상으로 사용하십시오.

PASS는 수행한 수치 검사 또는 육안 검사를 뜻합니다. 픽셀 단위 동일성, 프레임 보간 품질 또는 실제 게임 내 재생 검증까지 뜻하지 않습니다.

## 작업 팩 체크리스트

- PASS — 모든 PNG를 열어 지정 해상도, 유효한 알파 채널, 완전 투명 픽셀의 존재를 검사했습니다.
- PASS (육안) — 최종 이미지에 글자·숫자·로고·문장·종교 표식이 보이지 않습니다. 문서와 장부의 표면은 글자 없이 처리했습니다. 단순 사각/원형 광학 효과와 금속 버클은 포함됩니다.
- PASS (수치) — 아이콘 시트 1024×1024, 소품 시트 1024×256입니다.
- PASS (수치) — J01–J04에만 아이콘이 있으며 각각 204×204px 안전 영역 안에 있습니다. J05–J16의 알파 값은 전부 0입니다.
- PASS (육안) — 아이콘 순서는 작은 결계 / 그림자 군무 / 스승의 깃펜 / 회색 장부입니다. 그림자 군무에만 요청된 두 인물 실루엣이 있습니다.
- PASS (육안) — 소품 순서는 점등 의식진 / 봉인 의식진 / 온전한 서가 / 불탄 서가입니다. 상태 쌍에 공통 배율과 공통 하단 앵커를 적용했습니다.
- FAIL (엄격한 상태별 픽셀 정합) — 상태 쌍의 균열·외곽·질감과 디테일이 완전히 같은 픽셀에 겹치지는 않습니다. 중심/하단 위치는 맞췄고 육안상 크기는 유사하지만 완벽히 등록된 상태 애니메이션은 아닙니다.

## 제작 메모·잔여 차이

- 큰 의식진 후광은 경계 잘림 방지를 위해 최종 재제작에서 없앴습니다. 분홍빛은 두 원형 고리 선에 남겼습니다. 중간 수정의 회색 배경 결함이 있는 출력은 제외했습니다.
- 불탄 서가의 얇은 연기는 남겨 두었습니다. 의식진의 돌바닥은 원형 받침 안으로 제한했습니다.
- 40px 미리보기의 실루엣을 육안으로 확인했습니다. 게임의 실제 UI/전장에 적용한 상태는 검증하지 않았습니다.

## 동봉 파일 및 무결성

- manifest.csv에 최종 PNG의 파일 크기와 SHA256을 기록했습니다. A에는 manifest_icons.csv와 셀 매핑 CSV도 포함했습니다.
- contact_sheet.jpg는 파일명을 표시하며 1,000,000바이트 미만입니다.
- prompts_used/에는 원래 사용한 최종 생성 지시와 후속 교정 지시를 보존했습니다. 제외된 시도도 일부 기록되어 있으며, 최종 채택 여부는 이 보고서가 우선합니다.
- SHA256SUMS.txt는 자기 자신을 제외한 모든 동봉 파일을 포함합니다.
- PASS — 최종 ZIP을 다시 열어 전체 파일 목록을 읽고 CRC를 검사했으며, 모든 동봉 파일의 SHA256을 대조했습니다. 각 ZIP은 20,000,000바이트 미만입니다.

자동 검사 원자료: QA_METRICS.json. 이 ZIP은 아트 전달물이며 게임 코드 변경/실행 검증은 포함하지 않습니다.
