## 작업 팩 체크리스트

- PASS — 모든 PNG를 열어 지정 해상도, 유효한 알파 채널, 완전 투명 픽셀의 존재를 검사했습니다.
- PASS (육안) — 최종 이미지에 글자·숫자·로고·문장·종교 표식이 보이지 않습니다. 문서와 장부의 표면은 글자 없이 처리했습니다. 단순 사각/원형 광학 효과와 금속 버클은 포함됩니다.
- PASS (육안) — 인물별 4표정은 같은 얼굴·복장·조명·화면 구도를 유지합니다. 각 중립 이미지를 표정 수정의 기준으로 사용했습니다.
- PASS (육안) — 각 맵 시트에 4열×3행, 총 12프레임이 있고, 1행 아래/2행 오른쪽/3행 뒤 방향으로 구성되어 있습니다.
- PASS (수치) — 256px 셀별 알파 경계가 셀 내부에 있으며, 각 프레임의 하단 경계는 y=240(배타적 좌표)입니다. 모든 프레임의 아래 16행은 완전 투명합니다.
- PASS — 시트마다 하나의 등방 배율을 적용해 프레임 간 배율을 유지하고 크롭한 프레임을 공통 하단 기준선에 배치했습니다.
- PASS (육안) — 맵 인물의 핵심 복장과 색은 중립 초상과 일치합니다. 보행 B는 반대 발이 앞서도록 추가 수정했습니다.
- FAIL (엄격한 원본 크기 동일성) — 기존 맵 시트와 캐릭터가 차지하는 픽셀 높이·무기 폭이 정확히 같지는 않습니다. 셀 규격/발 기준선은 정확하지만 실루엣은 새 복장과 공격 포즈에 맞춰 재해석되었습니다.
- FAIL (표정 외 픽셀 완전 동일성) — 생성된 표정본 사이에는 머리카락·천 질감·알파 가장자리의 미세 변화가 있습니다. 같은 얼굴과 구도라는 육안 검사를 통과했지만, 얼굴 밖 픽셀이 완전히 동일한 편집본은 아닙니다.

## 제작 메모·잔여 차이

- 스승은 둥근 안경·흰 수염·종이 가방으로, 옛 상관은 회색 망토·짧은 머리·턱 흉터로 구분했습니다. 두 인물에 새 이름을 부여하지 않았습니다.
- 의식사는 셀 경계 잘림을 없애기 위해 큰 후광을 지팡이 케이지 내부의 작은 발광으로 바꿨습니다.
- 의식 기사의 긴 검 공격 폭을 셀 안에 넣기 위해 동일 배율로 전체 시트를 줄였습니다. 다른 인물보다 인체의 픽셀 높이가 작습니다.
- 걷기 A/B는 교정했지만 긴 로브 또는 망토가 다리를 가리는 프레임은 위상 차이가 작습니다. 실제 게임의 보행 루프는 검증하지 않았습니다.

## 동봉 파일 및 무결성

- manifest.csv에 최종 PNG의 파일 크기와 SHA256을 기록했습니다. A에는 manifest_icons.csv와 셀 매핑 CSV도 포함했습니다.
- contact_sheet.jpg는 파일명을 표시하며 1,000,000바이트 미만입니다.
- prompts_used/에는 원래 사용한 최종 생성 지시와 후속 교정 지시를 보존했습니다. 제외된 시도도 일부 기록되어 있으며, 최종 채택 여부는 이 보고서가 우선합니다.
- SHA256SUMS.txt는 자기 자신을 제외한 모든 동봉 파일을 포함합니다.
- PASS — 최종 ZIP을 다시 열어 전체 파일 목록을 읽고 CRC를 검사했으며, 모든 동봉 파일의 SHA256을 대조했습니다. 각 ZIP은 20,000,000바이트 미만입니다.
