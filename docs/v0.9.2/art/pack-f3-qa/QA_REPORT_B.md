- PASS (육안) — 인물별 4표정은 같은 얼굴·복장·조명·화면 구도를 유지합니다. 각 중립 이미지를 표정 수정의 기준으로 사용했습니다.
- PASS (육안) — 각 맵 시트에 4열×3행, 총 12프레임이 있고, 1행 아래/2행 오른쪽/3행 뒤 방향으로 구성되어 있습니다.
- PASS (수치) — 256px 셀별 알파 경계가 셀 내부에 있으며, 각 프레임의 하단 경계는 y=240(배타적 좌표)입니다. 모든 프레임의 아래 16행은 완전 투명합니다.
- PASS — 시트마다 하나의 등방 배율을 적용해 프레임 간 배율을 유지하고 크롭한 프레임을 공통 하단 기준선에 배치했습니다.
- PASS (육안) — 맵 인물의 핵심 복장과 색은 중립 초상과 일치합니다. 보행 B는 반대 발이 앞서도록 추가 수정했습니다.

- PASS (육안) — 리아는 기존 얼굴·갈색 눈·짙은 머리·넓은 챙 모자를 유지했습니다. 카이는 승인된 기존 얼굴을 다시 참조하여 짧은 옆머리, 올리브색 눈과 코의 흉터를 4표정에 복원했습니다.

- 카이 맵 시트의 눈·흉터·옆머리는 작은 전신 크기에 맞춰 단순화되어 초상의 세부를 모두 재현하지는 않습니다.
