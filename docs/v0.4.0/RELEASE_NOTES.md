## 그림과 연출
- **손그림 아트 85장:** 대화 반신 49장(5인 장수·아렌·발드릭·보스·NPC, 표정 4종)과 맵 스프라이트 시트 36종(4방향, 걷기·공격 프레임)입니다. 사용자가 제공한 원본을 해시 검증한 뒤 WebP로 내장했습니다.
- **고전 SRPG식 대화창:** 큰 반신 초상이 반투명 대화 상자에 겹쳐 나오고, 이름은 호박색으로 표시됩니다. 화면 아무 곳이나 누르면 진행되며, 버튼은 Auto/Skip만 남겼습니다.
- **걷기 동작:** 걸을 때 왼발과 오른발이 번갈아 움직입니다. 공격할 때는 대상을 바라봅니다.
- **군사는 리아 한 명:** 진영에 리아가 둘로 보이던 문제를 고쳤습니다. 이제 리아의 작전 탁자가 작전 회의를 여는 지점입니다.

## 출전 준비
- **출전 보드:** 왼쪽 대기, 오른쪽 출전 칸 사이로 장수를 드래그하거나 선택한 뒤 화살표로 옮깁니다. 에릭은 항상 출전합니다.
- **배치 화면:** 초상 패널에서 장수를 고르면 놓을 수 있는 칸이 파란색으로 표시됩니다. 프리셋은 '추천'만 남겼습니다.

## 전투 조작 (모바일 플레이 테스트 반영)
- 장수를 누르면 옆에 **이동 / 공격 / 스킬 / 도구 / 대기 / 상태** 메뉴가 큰 버튼으로 뜹니다. 이 단계에서는 칸을 표시하지 않습니다.
- **이동**을 눌러야 이동 가능한 칸이 표시됩니다. 이동한 뒤에는 이동 버튼이 **이동 취소**로 바뀝니다.
- 스킬이나 공격을 고른 뒤 대상을 누르면 예상 피해가 나오고, 같은 대상을 **한 번 더 누르거나 행동 확정**을 누르면 실행됩니다.
- 장수 그림을 직접 눌러도 선택됩니다.
- 'Guard'는 어디서나 쓰는 자기 태세가 되었습니다. 레벨업하면 HP/MP가 회복되고, 모든 치유로 EXP를 얻습니다. 지형 적성과 지형 보정, 화염 지형이 생겼고, 탭으로 나뉜 장수 정보창을 추가했습니다.
