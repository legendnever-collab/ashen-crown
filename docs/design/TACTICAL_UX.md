# Tactical UX — v0.3.1
Select → legal movement preview and adjacent contextual menu. Destination tap → walk preview → explicit confirm/cancel. Confirmed move retains action and pre-action undo. Enemy tap opens real attack forecast; archer minimum range remains enforced. Skills/tools/rescue/capture still use existing target/cost rules. Dock supplies portrait/vitals/context/next hero/end phase/settings.

Popup candidates on both sides and above/below are clamped to the field. Enemy/actionable centers outrank silhouette edge overlap; legal destination centers also protected. Extremely constrained screens may require the menu farther from the actor or internal menu scrolling. Quest body is informational and click-through; only summary toggles. Preference survives reload. Avoid duplicate-command execution with existing pointerdown/click pairing and transaction nonces.

Council supplies objective/terrain/intelligence/party/equipment/tools and deployment. Readiness checkboxes removed; only final departure confirmation remains. Defaults are playable without a purchase. M01–03, stage restart, defeat retry, saved RNG/growth and legacy import are required regression gates.
