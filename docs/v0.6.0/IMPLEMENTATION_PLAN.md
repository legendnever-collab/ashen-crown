   - 거점 마스크 (`hubs-v05.js`)
   - 세계 지도 (`world.js`)
   - 아트 import 스크립트

3. **원작 비복제.** 이름, 맵, 아트, 음악은 모두 오리지널로 만든다.
4. **실행한 검증만 보고한다.**
