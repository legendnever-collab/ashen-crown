## 결과

요청한 16개 이미지(실내 15장 + 상자 시트 1장)를 모두 제작했다. 아래의 형식·투명도·빈 상호작용 칸 검사는 통과했다. **스케치의 모든 가구 영역 및 상자 두 상태의 외곽선까지 완전히 일치하는 납품은 아니다.** 해당 항목은 FAIL로 기록한다. 작업 지시서 5절의 예외 규정에 따라 최선의 결과와 차이점을 함께 제공한다.

## 제작 및 후처리

- Built-in Imagegen으로 각 그림을 개별 생성했다. 최초 생성 순서는 jobs.csv의 1–16 순서다.
- 1번 마을 민가를 마을 계열 기준으로 사용했다. 2번 천막과 3번 요새를 먼저 만든 뒤 후속 방에 가족별 기준을 첨부했다. 기준 이미지의 최종 검수 수정은 후속 방 제작 뒤에도 이루어졌으며, 재질·빛의 기준은 유지했다.
- 레이아웃, 스케일, 외부 거점, 스타일 기준을 지정대로 참조했다. 별도 기존 게임·캐릭터·스튜디오 이름을 프롬프트에 추가하지 않았다.
- 실내는 RGB JPEG quality94로 저장했다. 생성 파일의 3:2 비율을 유지하고 최종 1536×1024를 확인했다.
- 상자는 최초 전체 시트를 선택했다. 별도 생성한 크기 교정 후보는 위치가 더 불안정해 채택하지 않았으며 납품에 포함하지 않았다.
- 요청된 스프라이트 크기·배치 처리를 위해 선택 시트의 24개 실루엣을 분리하고, 각 OPEN/CLOSED 쌍에 동일한 비율의 축소를 적용했다. 셀 중심과 고형 부분의 바닥선을 정렬한 뒤 6×4 atlas로 배치했다. 그림 내용은 이 단계에서 다시 그리지 않았으며 원래 alpha와 그림자 가장자리를 유지했다.
- 상자에 사용한 실제 최종 생성 프롬프트는 prompts_used/16_chests_act1.txt이며, 배치 후처리는 위 설명에 따른다. 실내 생성 및 선택 이미지에 적용된 수정 프롬프트도 prompts_used/에 포함했다.
- WebP 및 런타임 변환물은 포함하지 않는다.

## 구현팀에 전달할 주의점

완성 파일명과 1536×1024 캔버스는 지정 규격이다. 그러나 **가구 충돌 영역을 원본 스케치 좌표 그대로 확정하면 안 된다.** 최종 그림에서 이동 가능 영역을 다시 맞추고, 20개 상자 칸 및 2개 상인 칸은 현재의 빈 바닥 좌표를 유지해야 한다. 상자 전환은 위치 흔들림을 줄였지만 몸체가 픽셀 단위로 완전히 동일하지 않다. 게임 반영·캐릭터 합성·실제 전환 애니메이션의 실행 검증은 이번 아트 작업 범위에 포함되지 않았다.
