## 2. Global rules

- Painting style: match the attached approved art (style_aren_neutral.png, ref_bust_baldrick_neutral.png) — semi-realistic painted character art for a classic tactical RPG dialogue portrait: confident inked contour lines, painterly cel shading with soft gradients, strong warm rim light, rich saturated but slightly earthy colors, detailed metal and cloth textures, expressive mature faces (not chibi, not western cartoon, not photo-real). Original characters: do not copy any existing game's character, costume, emblem or logo.
- Never write the name of any existing game, character or studio in a prompt.
- **No text, letters, numbers, emblems, crests or logos** on clothing, shields, banners or anywhere. Faction identity comes from colors only.
- Busts: exactly 1024×1280, transparent background (or flat pure `#00FF00`), same framing as `style_aren_neutral.png`, turned to the viewer's right.
- Sprite sheets: exactly 1024×768, 4 columns × 3 rows of 256 px cells, feet on a baseline 16 px above each cell bottom, transparent (or `#00FF00`). Match the scale of the attached `ref_sprite_*.png` (they are shown at half size: 512×384).
- Do each named character in **one conversation thread**: neutral bust first, then the three expressions from it, then its sprite sheet. The face, hair, eyes, outfit and colors must stay identical across all of that character's images.
- Final sizes must be exact. If the generator returns another size, resize keeping the aspect ratio and pad (transparent) to the exact size. Do not stretch.
