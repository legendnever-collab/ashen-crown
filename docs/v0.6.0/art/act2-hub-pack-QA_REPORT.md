## 제작·후처리 기록

- 순서: 북부 도시 → 여관 및 5실 → Velmar → 주점 및 5실 → 상자. 이후 예약 칸/장식/창고 온도 수정.
- 생성 및 의미 편집은 이미지 생성 도구로 수행. 선택한 최종 결과에 이르는 원본 프롬프트와 수정 지시는 prompts_used/에 그대로 보관.
- approved_int_village_house.jpg는 제공 references에 없어서 지시에 따라 스케치와 실내 스케일을 사용. 이전 완료 작업의 chests_act1.png는 선택 참조로 사용.
- Velmar 생성 시 도구의 참조 5장 한도로 승인된 외부 지도 2장을 하나의 나란한 참조 이미지로 합침. 두 승인 지도, 레이아웃, 스케일, 캐릭터 스케일, 북부 도시를 모두 참조에 표현.
- 배경은 1536×1024 생성본을 RGB JPEG quality 94로 인코딩. 상자 최초 생성본 1254×1254는 비율을 유지해 크기를 조정한 뒤, 원본의 16개 알파 객체를 분리하여 각 쌍 공통 배율·셀 중심·하단 기준선에 맞춰 1024×1024로 재배치. 본체를 그리거나 형태를 변형하지 않음.
- 상자 가장자리 일부의 미세한 색 번짐과 비일치 윤곽은 남아 있음. 정밀 애니메이션용 동일 본체 레이어가 필요한 경우 추가 미술 작업 필요.
- contact_sheet.jpg는 식별자 포함 1MB 미만. 게임용 이미지에는 이 식별자가 없음.
