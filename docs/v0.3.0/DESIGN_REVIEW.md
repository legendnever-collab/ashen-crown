# Design Review
Primary measure: attachment to heroes and meaningful tactical preparation. Optional conversations explain existing membership without gating combat. Town click navigation and visited Fast Travel keep repetition short. A free two-potion field kit preserves baseline viability, purchased tools capped at six. No new mission or hero obscures core scope.
State risk: economy working copy must never overwrite practice canonical assets; first-clear only commit; forbid leaving ongoing battle via campaign selector; rollback persistent transactions on write failure. Raw growth and gear separate to prevent permanent stat inflation.
Canon audit: same 30 mission rows and three endings, no new faction ties, M03 memory repeats known facts. Local dialogue is PROPOSED content implementation. Subjective story pacing/music and real hardware require user review.
