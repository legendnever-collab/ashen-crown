## 1. 바뀐 점
- **그림 406장을 AVIF로 다시 저장했습니다**(초상 · 일기토 · 지도 그림 · 실내 · 거점 · 세계지도).
  - 해상도는 그대로입니다.
  - 그림마다 전과 비교해 기준을 넘는지 확인했습니다. 결과는 모두 넘었습니다.
- **비교 그림:** `docs/v2.2.1/screenshots/avif-compare-*.png`(왼쪽 전, 오른쪽 후)
  - 초상과 결정타 컷은 구별이 안 됩니다.
  - 실내 바닥과 거점 땅의 결이 조금 부드럽습니다.
- **그림을 여는 속도:** 큰 그림 394장을 한꺼번에 열 때 1.75–1.79초 → 1.49–1.55초로, 조금 빨라졌습니다.
- **AVIF를 못 여는 옛 브라우저**(Safari 16.4 이전)에서는 화면 위에 안내가 뜹니다. 누르면 닫힙니다.

## 2. 앞으로를 위한 장치
- **크기 예산:** 빌드할 때마다 크기를 재어 **80 MiB가 넘으면 경고, 90 MiB가 넘으면 빌드가 실패**합니다.
- **새 그림:** 그림팩을 들여오면 자동으로 AVIF로 바뀝니다.
- **저장소:** 게임 HTML은 릴리스 후보를 묶을 때만 커밋합니다. 지금까지는 고칠 때마다 60 MB씩 쌓였습니다.
- **지난 버전 보관**
  - 이 작업 환경에서는 GitHub Release를 만들 수 없어, 실행만 하시면 되도록 준비했습니다.
  - 병합 뒤 GitHub에서 **Actions → Archive old builds → Run workflow**를 한 번 눌러 주세요.
  - 지난 28개 버전의 Release가 만들어집니다(태그, HTML, 소스 묶음, 시험 보고서, 체크섬). 5개는 이미 있어 빠진 파일만 더합니다.
  - 그다음 버전에서 저장소의 지난 파일(약 1.85 GB)을 뺍니다. 시험은 Release에서 받아 씁니다.
