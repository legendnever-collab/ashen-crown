# Game Design Principles
CANON: Classic Fantasy Tactical SRPG / Original Fantasy World / Classic 16-bit Pixel Art / Browser & Standalone HTML.
CANON: 장수 중심, 아렌은 지휘관이며 기본 전투 장수와 분리, 자유 배치, 아군·적군 Phase, 반고정 성장, 고유 재능+전직+숙련, 전술 혁신형 각성, 유연한 군단 편성.
APPROVED_DIRECTION 장기 규모: 전체 장수 약 15–25, 출전 8–12. v0.2는 다섯 장수 모두 출전.
전직·각성은 새로운 행동(보호/차단/마력 지형/구조/위치 교환)을 제공해야 한다. 외형 Tier는 전직 시스템 완성의 대체물이 아니다. 성장, 서사, 전술을 연결하되 강제 희생·선택 진행 차단 금지.
