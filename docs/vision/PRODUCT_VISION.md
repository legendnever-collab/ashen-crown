# Product Vision
CANON: «장수를 키워 전쟁을 승리하고, 전쟁을 경험하며 장수의 이야기를 완성한다.»
Ashen Crown은 오리지널 세계의 전쟁 서사 Classic Fantasy Tactical SRPG다. 조조전의 육성·병종 조합·지형·턴 전술·성장 애착을 장르적 참고로 삼되 Sprite, 음악, 대사, 고유 시스템을 복제하지 않는다.
플레이어 감정: 첫 승리의 안도→동료의 성장에 애착→선택 비용에 고민→다음 이야기의 호기심.
Loop: Story → Town/Camp Exploration → NPC/Recruitment → Shop/Equipment → War Council → Free Deployment → Battle → Rewards/Growth → Aftermath → Next Story.
우선순위: 육성, 캐릭터 관계, 전술, 선택 결과, 서사, Pixel Art, 음악, 안정성, 확장성. 기능마다 애착·전술 선택·성장 체감·다음 미션 동기를 점검한다. 이야기는 갈등·정보·감정 변화로 전술 준비의 목적을 강화한다.
불변 원칙: 장수 중심; Aren 비출전 지휘관; 기존 성장 보존; 단순 수치 각성 금지; 세력의 장단점; 복잡 메뉴 소프트웨어로 전환 금지; standalone offline; CANON 무단 변경 금지.


CANON: «장수를 만나고, 함께 준비하고, 전장에서 성장시키며, 전쟁을 통해 그들의 이야기를 완성한다.» 아렌은 이야기와 군단 운영, 장수들은 전투의 주인공. 탐색·상점은 장수 육성에 기여한다.
